# AgriSentry Promotional Website

A static promotional website for the AgriSentry capstone project.

## Files
- `index.html` — main website
- `styles.css` — design and responsive layout
- `script.js` — mobile menu and subtle reveal animations

## Before publishing
1. Open `index.html`.
2. Find `https://YOUR-AGRISENTRY-APP-URL.example`.
3. Replace it with your actual deployed AgriSentry application/login URL.
4. Replace screenshot placeholders in the Preview section with real screenshots when available.

## Recommended deployment: Netlify
This site is static, so you can deploy it without localhost or a backend build.

### Netlify drag-and-drop
1. Sign in to Netlify.
2. Open the deployment/drop area.
3. Drag the entire `agrisentry-promo-site` folder into Netlify.
4. Netlify will publish a public URL ending in `.netlify.app`.
5. You can later connect a custom domain if desired.

## Alternative: GitHub Pages
1. Create a GitHub repository, for example `agrisentry-website`.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. In Repository Settings > Pages, configure deployment from your main branch.
4. The site will be available at a GitHub Pages URL.

Note: this promotional website is static. Your actual Laravel AgriSentry application should remain deployed on a PHP-compatible host such as your existing Hostinger environment; the promotional site's Access button should link to that live application.
